### 01 / ARCHITECTURE & PHILOSOPHY

- **色彩克制 (Chromatic Austerity)**: 严守单一中性基底与单强调色（`#82a1b9` / `#9cb4cd`），杜绝高饱和度警告色与刺目图章。
- **排版极性 (Typographic Polarity)**: 标题、哲思与题记采用古典衬线体 (Serif)；工程叙事与代码逻辑采用细体无衬线体 (Sans-serif)。
- **留白韵律 (Vacuum as Rhythm)**: 充沛的大面积留白作为阅读心理的停机坪，赋予字句以自洽的呼吸节奏。
