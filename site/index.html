排版规范检查

Chronicle 在导出前通过静态检查工具（lint.mjs）核对排版规则，确保输出符合设计定义：

GATE 01
严禁两端对齐 (No Justify)
正文始终保持左对齐（flush-left, ragged-right），避免拉扯字间距造成空白河流。
GATE 02
单强调色约束 (Chromatic Austerity)
除单一强调色（#537791 / #9cb4cd）外，不引入红黄绿等警告色。
GATE 03
正文字重 300 Light
叙事段落字重保持为 300 细体；加粗字重仅用于标题与元信息。
GATE 04
行高下限保证 (Line-Height)
Page 正文行高 ≥ 1.85；Slides 锁定 1.8；Resume 锁定 ≥ 1.7。
GATE 05
避免阴影滥用 (No Drop Shadows)
正文阅读流内不使用物理投影（左对话气泡微阴影除外）。
GATE 06
视野上限限制 (Field Ceiling)
阅读核心容器最大宽度控制在 896px 以内，横向保留至少 24px 安全间隙。

使用方式

Chronicle 可作为命令行工具独立运行，也可配置为 Agent Skill 供 Claude Code、Cursor、Codex 等工具调用：

# 安装到 AI Agent (Claude Code / Cursor / Codex)
npx skills add OwenCedaric/Chronicle -a claude-code codex cursor -g -y

# 本地克隆开发
git clone https://github.com/OwenCedaric/Chronicle.git
cd Chronicle && pnpm install

# 编译长文排版（导出 HTML、长图与 PDF）
node skills/chronicle/scripts/deliver.mjs article.md

# 导出社交图文卡片（指定比例或全部尺寸）
node skills/chronicle/scripts/deliver.mjs article.md --aspect 3:4
node skills/chronicle/scripts/deliver.mjs article.md --aspect all

# 导出演示幻灯片
node skills/chronicle/scripts/deliver.mjs slides.md --format slides

# 导出个人简历
node skills/chronicle/scripts/deliver.mjs resume.md --format resume
